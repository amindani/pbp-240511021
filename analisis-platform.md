# Analisis Komparatif Platform (Web, Desktop, Mobile)

## Tabel Komparasi Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Teknologi pengembangan** | Menggunakan HTML untuk struktur halaman, CSS untuk tampilan, serta JavaScript atau TypeScript untuk interaksi. | Menggunakan bahasa dan framework seperti C#, .NET, C++, Java, dan JavaFX sesuai kebutuhan aplikasi. | Menggunakan Kotlin atau Java untuk Android, Swift untuk iOS, serta Flutter atau React Native untuk pengembangan lintas platform. |
| **Arsitektur aplikasi** | Umumnya menggunakan arsitektur client-server, dengan browser sebagai antarmuka pengguna dan server untuk memproses permintaan serta menyediakan data. | Dapat berjalan sebagai aplikasi lokal, menggunakan layanan server, atau menggabungkan pemrosesan lokal dengan layanan daring. | Menggunakan komponen antarmuka dan pengelolaan data, serta dapat terhubung ke API server dan menyimpan data secara lokal. |
| **Cara distribusi** | Diakses melalui URL menggunakan browser. Progressive Web App (PWA) juga dapat dipasang pada perangkat yang mendukungnya. | Umumnya didistribusikan melalui paket instalasi seperti `.exe`, `.msi`, atau `.dmg`, maupun melalui toko aplikasi. | Didistribusikan melalui Google Play Store, Apple App Store, atau metode instalasi lain yang didukung perangkat. |
| **Kelebihan** | Mudah diakses melalui browser yang kompatibel dan pembaruan pada server dapat langsung tersedia bagi pengguna. | Mendukung integrasi dengan sistem operasi dan perangkat keras serta dapat menjalankan pemrosesan secara lokal. | Mudah dibawa, mendukung antarmuka sentuh, dan dapat memanfaatkan fitur perangkat seperti kamera, GPS, sensor, serta notifikasi. |
| **Keterbatasan** | Akses perangkat keras tertentu dibatasi oleh browser. Fitur daring membutuhkan internet, kecuali aplikasi menyediakan dukungan offline. | Membutuhkan proses instalasi atau distribusi yang sesuai. Kompatibilitas dan pemeliharaan dapat berbeda pada setiap sistem operasi. | Pengembangan perlu memperhatikan ukuran layar, konsumsi baterai, kapasitas memori, serta perbedaan perangkat dan versi sistem operasi. |
| **Contoh aplikasi** | Google Docs versi web, Trello versi web, dan Figma versi browser. | Visual Studio Code, Adobe Photoshop, dan Microsoft Word versi desktop. | WhatsApp, Gojek, dan Instagram versi Android atau iOS. |
| **Penggunaan yang sesuai** | Sistem informasi akademik, toko daring, portal berita, dan aplikasi kolaborasi berbasis browser. | Perangkat lunak desain, pengembangan program, pengolahan data, dan aplikasi produktivitas komputer. | Aplikasi transportasi, navigasi, komunikasi, transaksi digital, dan aplikasi yang memanfaatkan sensor perangkat. |
