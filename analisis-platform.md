# Analisis Komparatif Platform (Web, Desktop, Mobile)

## Tabel Komparasi Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML, CSS, dan JavaScript merupakan teknologi utama pengembangan web. TypeScript juga sering digunakan untuk membantu pengembangan aplikasi yang lebih terstruktur. | Menggunakan bahasa pemrograman sesuai teknologi yang dipilih, seperti C#, C++, Java, dan Python. Framework yang digunakan bergantung pada sistem operasi dan kebutuhan aplikasi. | Kotlin dan Java umum digunakan untuk Android, sedangkan Swift digunakan untuk iOS. Dart dengan Flutter dan JavaScript atau TypeScript dengan React Native dapat digunakan untuk pengembangan lintas platform. |
| **Arsitektur** | Umumnya menggunakan arsitektur client-server. Browser berperan sebagai client untuk menampilkan antarmuka, sedangkan server dapat menangani logika aplikasi dan penyimpanan data. | Dapat menggunakan arsitektur aplikasi lokal, client-server, atau gabungan keduanya. Pemrosesan dapat dilakukan langsung pada komputer atau melalui layanan server. | Umumnya menggunakan arsitektur berlapis yang memisahkan antarmuka, logika aplikasi, dan pengelolaan data. Aplikasi juga dapat berkomunikasi dengan server melalui API. |
| **Cara distribusi** | Umumnya diakses melalui URL menggunakan browser tanpa instalasi tradisional. Pembaruan aplikasi web dilakukan melalui server, sedangkan Progressive Web App (PWA) juga dapat dipasang pada perangkat yang mendukungnya. | Umumnya didistribusikan melalui paket instalasi seperti `.exe`, `.msi`, dan `.dmg`, atau melalui toko aplikasi. Metode distribusi bergantung pada sistem operasi yang digunakan. | Dapat didistribusikan melalui Google Play Store dan Apple App Store. Android juga mendukung distribusi melalui paket `.apk`, sedangkan aplikasi iOS umumnya didistribusikan dalam paket `.ipa` melalui mekanisme yang didukung Apple. |
| **Keunggulan** | Dapat diakses dari berbagai perangkat yang memiliki browser kompatibel. Pembaruan di sisi server dapat tersedia bagi pengguna tanpa mengharuskan mereka memasang ulang aplikasi. | Dapat memanfaatkan kemampuan sistem operasi dan perangkat keras komputer. Cocok untuk aplikasi yang membutuhkan pemrosesan lokal, integrasi perangkat, atau penggunaan sumber daya komputer secara intensif. | Mudah dibawa dan digunakan saat bepergian. Dapat memanfaatkan fitur perangkat seperti kamera, GPS, sensor, biometrik, dan notifikasi sesuai izin serta dukungan sistem operasi. |
| **Keterbatasan** | Akses terhadap perangkat keras dan fitur sistem tertentu bergantung pada kemampuan serta izin browser. Aplikasi yang membutuhkan layanan daring memerlukan koneksi internet, kecuali tersedia dukungan offline. | Memerlukan instalasi atau proses distribusi yang sesuai. Pengembangan dan pemeliharaan dapat menjadi lebih kompleks ketika aplikasi harus mendukung beberapa sistem operasi. | Pengembangan perlu memperhatikan ukuran layar, konsumsi baterai, memori, dan perbedaan perangkat. Aplikasi juga harus mengikuti persyaratan platform dan proses peninjauan toko aplikasi jika didistribusikan melalui toko resmi. |
| **Contoh aplikasi** | Google Docs versi web, Trello versi web, dan Figma versi browser. | Visual Studio Code, Adobe Photoshop versi desktop, dan Microsoft Word versi desktop. | WhatsApp Mobile, Gojek, dan Instagram versi Android atau iOS. |
